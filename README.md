# Who Is the Greatest Premier League Attacker? A Statistical Analysis

## Research Question

**Using publicly available statistics, which player has the strongest statistical case for being the greatest attacker in Premier League history?**

---

## Project Goal

The goal of this project is to compare some of the greatest attacking players in Premier League history using objective data rather than opinion. Instead of asking "Who is the GOAT?", this project evaluates each player across multiple statistical categories, including goalscoring, efficiency, longevity, peak performance, and team success.

## Statistics Being Compared

### Career
- Appearances
- Minutes Played
- Goals
- Assists
- Goal Contributions

### Goalscoring
- Goals per 90
- Non-Penalty Goals
- Minutes per Goal
- Hat Tricks
- Golden Boots

### Efficiency
- Goal Contributions per 90
- Shot Conversion %

### Longevity
- Seasons Played
- Seasons with 20+ Goals

### Peak
- Goals in Best Season
- Goal Contributions in Best Season

### Success
- Premier League Titles
- Premier League Player of the Season Awards
